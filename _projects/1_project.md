I implement two reverberations, image source reverberation and the spring reverb, and a distortion guitar effect in real time. The levels of reverberation and distortion can be adjusted through either the Bela GUI or the breadboard. The system supports both playing a loaded audio file and playing guitar sounds in real time. The experiment shows real-time image source reverberation can only support reverberation orders lower than two, and the resulting reverberation is not that realistic.
